## 归档说明

1. 原有正文、设定与图像均原样保留；此次整理只新增仓库说明与 Git 文件规则。
2. 早期六千字大纲、八千字／一万字草稿、十章稿和八章旧版均保留供对照，不能直接视为当前正文。
3. 文本与视觉试样中仍可能存在作者已指出、尚待继续修订的问题；“完整归档”不等于“内容已全部通过审定”。
4. 一些历史文档含本机绝对路径。专案目录内的文件可通过本页相对链接访问；目录外的旧聊天、其他专案和本机技能环境不在此归档范围。
5. 此归档没有附加开源许可；外部参考图片的来源身份与使用许可不因归档发生变化。上传目标按私有仓库准备。

后续创作与改稿须遵守 [AGENTS.md](AGENTS.md)。
