# 剧本小说读者时间线 v3

> 本文件只规定读者在小说中接收事件、视角与信息的顺序，不是作者层客观时间线，也不是12章逐章大纲。章数只用于锁定少数已经确认的信息门槛，具体场景与章内篇幅留待下一阶段处理。

## 一、总原则

- 精神病院关系线是小说的时间脊柱：除正常时间省略外，事件始终向前推进，不打乱发生顺序。
- 开篇把时间较后的男主外层梦伪装成当前现实；医院线推进到现实共死邀请后，才无缝接回开篇坠落的同一瞬间。
- 人物过去不以完整传记交代，而由当前的声音、动作、物件和身体反应触发。读者先看见行为结果，再逐步倒推创伤原因。
- 杀人夜先完成埃利奥特的身份误认与主动识别，再回卷卡琳娜版本；卡琳娜版本与埃利奥特退回的外层梦错位交叉，不机械复述同一高潮。
- 章节不标注人物、年代、现实或梦层，只使用中性意象命名；读者可以怀疑哪层真实，但必须清楚当前是谁在行动和感受。
- 所有非线性手法都必须服务最高命题：梦如何把依恋对象重塑成可被需要的载体，并在提供救援以后逐渐侵蚀现实判断。

## 二、读者实际接收顺序

### 1. 外层梦冷开场：把后期误认成现在

朋友把埃利奥特送到废弃酒店。他进入烧毁建筑，发现1814门牌和走廊尽头的女性；脚下地板坍塌，叙事切断。

- 手法：预叙式冷开场；从全书结构看形成倒叙开篇。
- 读者暂时判断：这是现实现在时，埃利奥特主动来调查酒店。
- 暂不说明：这是现实共死危机之后、埃利奥特在医院睡着后进入的外层梦。

### 2. 倒回医院关系起点：伪治疗关系成立

叙事切到卡琳娜谈论噩梦，埃利奥特提问、记录和引导。场所只通过灰白墙面、窄窗、门锁等局部出现，不提供任何真正的医生权限。

- 手法：从开篇较晚时间倒回关系形成期。
- 视角权限：埃利奥特拥有完整的当前意识；卡琳娜只有外部动作、对白和短促感官裂缝，不进入她对埃利奥特病友身份的完整判断。
- 读者暂时判断：埃利奥特可能是心理医生或治疗者，卡琳娜是被引导的一方。

### 3. 卡琳娜第一次感官回忆：过去侵入现在

鸟撞上医院窗户。卡琳娜短暂看见玻璃后的翅膀、母亲的外套、烟味或火光，但不解释母亲后来发生了什么。

- 手法：无分隔的短促记忆侵入。
- 进入与返回：由撞窗声滑入过去，再由医院窗上的羽毛或埃利奥特拉下百叶窗返回。
- 功能：先让读者体验创伤形状，不提前获得人物传记答案。

### 4. 旧案碎片渗入谈话：不形成完整闪回

火灾、屋顶、雨棚、洗衣车、白床单、1814钥匙和维多利亚以互相冲突的碎片出现。它们可能是卡琳娜的记忆、梦、长期治疗后的重述或他人灌输。

- 手法：碎片化插叙与不可靠转述。
- 限制：不进入客观旧案全景，不由可靠来源确认凶杀或真凶。
- 功能：读者接收到旧案存在，却无法把卡琳娜的主观罪责当成客观罪证。

### 5. 第2章结尾的完整插叙：第二种废墟抵达

1814门牌、敲墙声或烧黑墙面触发埃利奥特的回忆：没有朋友，他曾精神失常地独自醒在废墟，逃到便利店；老板只确认酒店发生过火灾，随后报警并使他被送医。

- 手法：带场景分隔的完整插叙。
- 与开篇的公平差异：朋友／无人陪伴、状态正常／衣着混乱、主动进入／不知如何越过围栏、梦中指控／现实老板只确认火灾。
- 读者问题由“谁是凶手”转向“为什么开篇与这段完整记忆呈现两种互不相容的抵达”。由于开篇是医院线后期才会发生的外层梦，此时的埃利奥特尚未经历它，不能主动比较两个版本；矛盾暂时只属于读者的信息优势。

### 6. 医院线继续顺叙：卡琳娜开始反向观察

卡琳娜逐渐记住埃利奥特按住左腕、看门、扣笔帽和回避回答的方式。她不说破，只模仿和返还。停电时埃利奥特短暂失去现实判断，卡琳娜第一次使用他教给她的方法把他拉回来。

- 手法：主线顺叙；夹入埃利奥特尚不完整的身体记忆。
- 关系变化：被引导者第一次成为引导者；梦与心理此时仍主要表现为恩赐和救援。

### 7. 第4章结尾身份揭晓：男主也是病人

制度性动作同时约束两人：工作人员叫出两人的编号，收走埃利奥特的笔并要求他服药。读者确认埃利奥特没有医生身份。

- 手法：主线中的身份反转，不是倒叙。
- 回溯效果：此前所有提问、记录和帮助都仍然真实，但被重新理解为病友借用治疗者姿态满足拯救需求。
- 第5章起开放卡琳娜完整的医院当前意识，男女主进入不机械轮换的平等双视角。

### 8. 卡琳娜完整童年回忆：母亲没有回来

在身份揭晓、关系较为平等以后，撞窗、外套或烟味再次触发卡琳娜沉入较完整的六岁记忆：母亲先放走困在室内的椋鸟，住宅起火后又用同一件外套包住卡琳娜、把她推出窗口，自己没有下来。

- 手法：有空行或场景分隔的沉入式回忆；不写年代标签。
- 对话只保留记忆结论，例如“他们说她去了另一个地方”，不让卡琳娜把完整往事重新口述一遍。
- 叙诡功能：过去的火、离开和醒来逐渐组成她的世界模型，但尚未直接指向现实共死计划。

### 9. 依恋成为恩赐：医院顺叙与时间省略

华尔兹、折纸留言、分橙子、错过约定、现实定位和互相照顾依次发生。每章保留一个主要当前时视角，不严格男女轮换。

- 手法：顺叙为主；“几周后”“此后”等只承担时间省略，不改变事件次序。
- 语言变化：卡琳娜开始使用埃利奥特的问句，埃利奥特开始使用卡琳娜的意象。
- 主题状态：梦、仪式和互相理解仍让他们第一次拥有暂时的家。

### 10. 第6章末或第7章开端的中点：主动确认错误现实

卡琳娜认为医院走廊少了一扇门。埃利奥特明知那里一直只有三扇门，却重新数过并告诉她确实少了一扇。

- 手法：医院时间脊柱中的正向事件，不是回忆或梦。
- 结构作用：同一套现实定位方法从“把人带回来”变成“共同维护错误现实”。
- 主题转折：梦由恩赐转为惩罚；埃利奥特第一次不是被动误认，而是为了不失去卡琳娜主动选择私人现实。

### 11. 依恋侵蚀现实：顺叙中穿插埃利奥特创伤碎片

两人替彼此隐瞒症状、对工作人员撒谎、弱化外部治疗锚点。埃利奥特确认呼吸、清点药物、拒绝先睡和按住左腕的行为逐渐触发姐姐的轮廓，但不完整复原死亡。

- 手法：短促无分隔记忆；先呈现手、药片、呼吸和床边，暂不交代因果。
- 卡琳娜只能拼出“他曾经醒得太迟”，不知道完整事实。
- 关系变化：双方不再只是互相安抚，而开始成为彼此唯一的现实证明。

### 12. 第8章：死亡信念变成行动可能

转院从风声发展为迫近决定。卡琳娜的假醒记录、死亡方式和“谁与她一起回来”逐渐完整；她把自己与埃利奥特圈在同一层、同时醒来的位置。

- 手法：医院主线继续向前；童年火灾和酒店唯一幸存只以短暂回声进入。
- 信息门槛：读者此前知道她相信死亡可能通向另一层，到这里才意识到她可能把该信念用于维系两人的依恋。
- 不把共死意图写成突然的危险反转。

### 13. 第9章现实危机：姐姐记忆完成，男主拒绝

卡琳娜把共同死亡计划推进到可执行边缘，邀请埃利奥特与她一起醒来。埃利奥特被她的动作、药物或呼吸触发，终于短暂回到姐姐死亡的那一夜：他曾答应不向外求助，以为自己已经使姐姐平静，在陪伴中睡着，醒来时已经太迟。

- 手法：现实共死邀请中的沉入式回忆；过去与现在由睡眠、呼吸或手腕连接。
- 回忆在拒绝以前完成，使读者理解其行动根源，不把动机留给杀人夜补写。
- 埃利奥特拒绝不是拒绝卡琳娜，而是不愿再次让依恋对象死在自己身边。两人被院方分开并入睡。

### 14. 第10章接回开篇：同一次坠落继续

叙事从开篇地板坍塌的同一瞬间继续：埃利奥特撞上下层地面，发现朋友车辆已经消失，在废墟客房躺下；再次睁眼时，酒店恢复到火灾以前。

- 手法：倒叙框架闭合，不另写成第二次相似的废墟梦。
- 读者此时确认：开篇属于现实危机之后的男主外层梦。
- 埃利奥特在外层梦中睡着，进入内层杀人夜，形成梦中梦。

### 15. 第10章男主版杀人夜：误认、识别与死亡

埃利奥特把“可被自己成功拯救的卡琳娜”凝缩到维多利亚身上，把真正同行的卡琳娜看成另一名女性。维多利亚中途死亡；现实定位语言、火灾前后两张空间地图和1814钥匙使他主动认出同行女性始终是卡琳娜。

- 手法：内层梦中的顺叙。
- 信息门槛：男主完成身份揭晓以后，才允许读者进入卡琳娜无误认的完整梦中视角。
- 卡琳娜重演现实邀请；埃利奥特再次拒绝并被她杀死，随后坠回独属外层梦。

### 16. 第11章回卷卡琳娜版本，并与外层梦错位交叉

卡琳娜版本回到杀人夜开场。她从未借用他人面貌，始终知道自己是谁，也知道埃利奥特每次看向她时都在看见别人。只重写能够增加主体差异、动机与关系意义的场面。

叙事按意义而非客观同步交叉：

1. 卡琳娜看见埃利奥特先保护维多利亚；埃利奥特从死亡退回废墟并寻找出口。
2. 卡琳娜杀死维多利亚并取走1814钥匙；埃利奥特在外层梦中走向便利店。
3. 卡琳娜杀死梦中的埃利奥特、纵火并沉入水箱；便利店老板开始把酒店罪责指向卡琳娜。
4. 卡琳娜从水箱梦中醒回医院；埃利奥特仍留在外层梦。

- 手法：回卷式倒叙＋平行交叉。
- 限制：交叉不表示两人进入同一场客观梦，也不表示主观梦时钟同步。
- 维多利亚的旧案罪责不设置独立揭晓；读者只能从她的空间位置、1814钥匙、尚未发生的烟灰和不属于男女主投射的凝视，在第11章后反向推断。

### 17. 卡琳娜转院与男主外层梦：动作对应式交叉

卡琳娜现实中停在埃利奥特病房外，把手贴在观察窗；外层梦里，街对面的年轻卡琳娜向埃利奥特抬手。现实中的她收回手，把折成三折的纸推进门缝，随后走向转院车辆；梦中老板则指认卡琳娜是凶手，投影没有靠近埃利奥特。

- 手法：动作对应式平行交叉。
- 主题作用：两人看似同时抵达彼此，却被玻璃、梦层和不同现实隔开。
- 限制：对应动作只表达心理共振，不成为共享外层梦的证据。

### 18. 第12章晚醒与尾声：无法完成放手

转院车辆离开后埃利奥特才惊醒。他本能冲向出口，只看见雪地上的新鲜车辙；返回空房间后才发现折成三折的纸和“有一天我们一定会再见的”。

他无法判断追赶是再次把卡琳娜变成拯救对象，还是不追赶便等于重复过去的遗弃；也无法判断她没有叫醒自己是在放手，还是仍等待他穿过另一层寻找。

最后，他在医院走廊看见不应存在的酒店服务楼梯，使用两人的现实定位节奏敲墙却没有回应。楼梯恢复为坚实墙面，但他无法因此相信自己已经醒来。

- 手法：线性尾声＋单一空间裂缝。
- 内心处理：采用自由间接叙述，不使用长篇解释性独白。
- 最终效果：相对梦层结构可以重建，终极现实仍不可证实；失去共同现实以后，放手本身也失去了可以验证的意义。

## 三、非线性手法分工

| 手法 | 在本版本中的位置 | 叙事任务 |
|---|---|---|
| 预叙／倒叙开篇 | 废墟冷开场，随后倒回医院关系起点 | 让读者先把外层梦当现实 |
| 碎片化插叙 | 卡琳娜旧案、梦和治疗后的混合记忆 | 提供材料但不完成客观定罪 |
| 完整插叙 | 第2章埃利奥特客观废墟经历 | 制造两种抵达版本的第一道时间裂缝 |
| 感官侵入式回忆 | 撞窗、左腕、药片、呼吸、外套等触发 | 先呈现创伤后果，再倒推原因 |
| 沉入式回忆 | 卡琳娜童年火灾、埃利奥特姐姐死亡 | 完成人物伤口，但不写成口述传记 |
| 回卷式重叙 | 男主版杀人夜结束后返回卡琳娜版本开场 | 改写同一事件的关系意义，而非重复悬念 |
| 平行交叉 | 卡琳娜梦／医院现实与埃利奥特外层梦 | 表现错时、共振和无法互证 |
| 时间省略 | 医院关系发展中的“几周后／此后” | 压缩重复日常，不改变医院事件顺序 |

## 四、视角权限

- 第1—4章：埃利奥特拥有完整当前意识；卡琳娜只开放对白、外部动作与感官型回忆裂缝。
- 第4章结尾身份揭晓后：开放卡琳娜完整医院当前意识，男女主视角平等，但每章仍设一个主要当前视角。
- 第1—9章：不在同一场景中自由跳入两人完整意识；短回忆可以由感官短暂侵入。
- 第10章：埃利奥特主导外层梦与男主版杀人夜。
- 第11章：卡琳娜主导杀人夜回卷，并允许与埃利奥特外层梦明确交叉。
- 第12章：先完成卡琳娜离院与埃利奥特外层梦的交叉，再回到埃利奥特晚醒后的单一视角。

## 五、回忆呈现规则

- 一至三段的记忆碎片不使用场景分隔，直接由现实感官滑入并由相同感官返回。
- 较完整的创伤回忆使用空行或分隔符，但不标注年代、地点或“回忆”。
- 不用长段斜体，不以“她想起”“他回忆道”反复提示。
- 每次回忆必须解释或重新解释当前的一个动作，并使人物随后作出不同选择；不能只增加背景资料。
- 卡琳娜的记忆允许图像和次序变化；埃利奥特的事实碎片相对稳定，但会回避自己曾垄断照料、延误外援的意义。

## 六、不得突破的边界

- 不把精神病院主线也全面打乱；它必须是读者判断前后因果的时间脊柱。
- 不在身份揭晓前利用卡琳娜完整内心故意回避“埃利奥特也是病人”的事实。
- 不用完整客观旧案回放解释维多利亚罪责。
- 不在男主主动认出女主以前开放卡琳娜无误认的完整杀人夜视角。
- 不让卡琳娜版本机械复制男主版；重复场面必须产生新的主体信息和关系转折。
- 不给章名添加人物、年代、现实、梦境或层级标签。
- 不让叙诡凌驾主题。每一道误认最终都必须回到同一个问题：人物看见的是独立真实的对方，还是由自身创伤和依恋需要重塑出的载体。
