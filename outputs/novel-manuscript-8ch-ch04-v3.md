# 第四章　第一拍

埃利奥特回来以后的第一个星期，两个人都不太会坐在同一边。

从前桌子隔在中间，他问，她答。现在一抬手就可能碰到对方的杯子，卡琳娜反而更常不说话。第一个星期他没带那本软皮本。第二个星期带来了，合着放在椅子边上，只在他自己屋里写。她从他偶尔停住的目光里看得出来，他还在记；可她说的话不会再当着她的面变成一行字。有一次她问他这几天都记了什么，他把本子递过来让她翻。院子里的长椅，走调的钢琴，他自己凌晨醒来的钟点。写她的那一页空着。

有天下午，他看着窗外说，今年的雪下得晚。

“雪不认得日历。”卡琳娜说。

他笑了一下，接着张嘴，她看出他要问她昨晚睡得怎样，先截住了：“今天只谈天气。不是每件事都得绕回我的梦里。”

“我是怕你不想谈天气。”

“你说一句，我也能接一句。”她把自己的杯子挪到窗边，“我们都知道对方会谈梦了。说点别的，不算浪费。”

他便说院子里那张长椅，昨晚结了冰，早上有人坐上去，起身时大衣差点被冻在上面。卡琳娜想那个人板着脸跟一张长椅抢自己的衣摆，忍了好一会儿，还是笑出了声。笑声很短。笑完她自己也愣了一下，好像很久没听过这个声音。

离开谈话室前，她说：“明天要是下了雪，你再告诉我长椅怎么样。”

她说的是长椅。他点头的样子，像听见的是明天。

＊

活动室里那只鸟，是一场雨以后飞进来的。

通风窗被风推开半掌宽，一只椋鸟挤进来，绕着灯飞了一圈，撞上对面的玻璃。有人大叫，工作人员去拿毛巾。卡琳娜已经站到门口了，想不起自己是怎么走过去的。她按着门框，耳朵里是翅膀拍打的声音，眼前却是另一扇更矮的窗。

六岁那年，她家厨房也飞进过一只椋鸟。

母亲怕它伤着她，让她先躲到桌子底下，自己从椅背上取下那件羊毛外套。鸟一次次朝亮的地方撞。卡琳娜趴在桌下，看见母亲的鞋尖跟着它在地上移。

“它会啄你。”她说。

“它只是在找出去的地方。”

母亲把外套张开，等鸟落到碗柜顶上，才慢慢走过去。外套裹住它的时候，卡琳娜以为母亲要把它闷死。窗推开了，雨一下子扑进屋里。母亲把手伸到窗外，松开。鸟贴着屋檐飞了一阵，钻进灰色的树后面不见了。

“它知道这是我们家吗？”卡琳娜问。

“它有它自己的地方。”

“那你为什么放它走？”

母亲没有回答，把湿外套搭到暖气上。母亲有时能陪她把同一本书从头念到尾；有时一整夜坐在厨房里，卡琳娜叫她，像叫一个听不见的人。孩子分不清那是累还是生气，只知道走得太近，母亲可能会抱住她，也可能把眼睛转向窗外。鸟飞走以后，母亲看窗户的时候并没有变少。

着火的那天夜里，屋里比白天还亮。卡琳娜在咳嗽里醒过来，身上裹着同一件羊毛外套。母亲用椅子砸开卧室的窗，楼下有人拉开一条毯子。卡琳娜攥着母亲的袖子不肯先下去。母亲俯下身，嘴贴着她的耳朵，说自己随后就来。她掉得太快，母亲后半句说没说出口，她没听清。

毯子接住了她。有人把她抱进隔壁屋，往她手里塞了一杯热水。她一直盯着门，等母亲披着那件烧坏的外套走进来。外面的人不让她回去。后来有人告诉她，母亲到另一个地方去了，不疼了。

“哪个地方？”她问过很多人。

大人们给过不同的回答。她最后记住的不是哪个地名，是那个“到”字。好像母亲没有消失，只是先一步走过了一扇她还看不见的门。

家烧了以后，她住过好几个地方。别人家的拖鞋总比她的脚大一号，她的箱子常被挪到客厅的角落。每次有人好心替她收拾东西，她都要把那件外套翻出来，确认它还在。外套后来小得再也披不上，她还是不肯扔。十八岁以后，住处换成了机构：评估、安置、再评估。她学会在一小时里把衣服、杯子和书收进两个包，却从来没有一把属于自己的钥匙。

假醒是从很早就开始的，比她记得住的任何一间病房都早。每次醒来，她都能说出昨晚怎么关的窗、哪只杯子里剩着水；再睁一次眼，那些都不在了。有时她在梦里从很高的地方往下掉，下一刻落进厨房；有时火从门缝里钻进来，她却在一张白床单底下醒来。起初她怕死。后来她怕的是，自己醒了，母亲没有。

活动室里的鸟又撞了一下玻璃。

卡琳娜一下子回到门口，指甲陷进门框的软漆里。工作人员终于用毛巾罩住那只鸟，从通风窗送了出去。有人问她要不要回房，她摇头，可是回不到那排椅子那边去。

埃利奥特站在几步外。他没走近，也没说鸟不危险。等工作人员把窗关好，他才问：“你想在这儿等一下，还是去走廊？”

“我不想从这扇门出去。”

“那就不出去。”他在她旁边蹲下，把挡住她视线的一把椅子挪开，“它已经飞走了。你要是想看看窗户，我陪你走过去。”

她不想看窗。她坐到门边的长椅上，等手指自己松开。他一直没碰她。等她的呼吸平下来，他才把一杯水放在她够得着的地方，没有塞进她手里。她看着那杯水，过了一会儿，自己伸手拿起来。

“我母亲也放走过一只鸟。”她说。

埃利奥特朝通风窗看了一眼。“她抓住它一定很难。”

“她比你灵巧。”

“我还没抓过。”

“我知道。”她握着杯子，“我是在告诉你，你现在不用去证明。”

他看着她。她没有讲那场火，把杯子里的水喝完了。

＊

卡琳娜有一本薄薄的记录册，封面起了毛边。夜里醒来，她会写几行，免得天亮以后只记得怕，不记得怕从哪儿来。每页分成三栏：最后记得什么；接着醒在哪里；醒来时身边是谁。前两栏常有字，第三栏多半空着。

有一次埃利奥特看见她在第一栏写了一个“火”字，问能不能翻。她把本子递过去，先说清楚：“这不是一本能把我判清楚的病历。”

“我只看你愿意让我看的。”

他翻到几个反复出现的房间，翻到同一夜里写下的两个不同的早晨。没有一页写着“死亡证明了什么”。他把本子合上。

“这些对不上的醒来，你为什么都留着？”

“因为每一次都像真的。”她说，“我知道你会说，人不可能从一间着火的屋子，醒到另一间屋子里。”

“我不会拿这个去否认你感觉到的东西。”

“那你会怎么说？”

“我会说，现在这本子在我手里。你给了我，我看过了，再还给你。至少这几分钟，我们可以一起记。”

卡琳娜把本子接回来。有个问题已经到了喉咙口：要是两个人在同一刻死去，是不是也能一起记得下一个房间？她没让它出来。埃利奥特以为她在看那一页的日期，把笔递给她。她在第三栏写下一个名字，写完很快把那一页合上了。

几天以后，轮到她看见他的空白。

他陪她在院子里走。每过一道门，他都要看一眼玻璃上的倒影。她知道他最近睡得不好，也知道他半夜总要去听隔壁的人还有没有呼吸。他从不说那个人是谁，问急了，只说自己习惯醒得早。

走到东楼时，一个护工推着空床从电梯里出来，床栏在地砖上弹了三下。埃利奥特的脚停住了，眼睛跟着那张床走了很远。护工进了门，他还盯着那块空地，右手按着左腕，像在替谁数脉搏。

“我想去院子那一边。”卡琳娜说。

他没应。她走到他视线前面，没有去挪他的手。

“那张床已经进去了。”她说，“你现在跟我走，还是我在这儿等你？”

过了一会儿他才说：“等我一下。”

她就等。他终于抬头的时候，脸上是一种既被人看见、又不想被人看见的窘。她没有问那张床让他想起了谁，先指着前面的窄台阶：“那儿有块冰。你刚才要是接着往前走，就得我反过来扶你了。”

“你会扶吗？”

“会。不过先提醒你比较省力。”

他们绕开了那级台阶。他一路没解释。回到谈话室，他在纸上画出那张床走过的路线：电梯，门，空地。他把这张纸推到两人中间，没等她问。

＊

那年冬天，活动室搬来一架旧钢琴。有两个琴键总慢半拍，弹琴的人索性把一支三拍子的曲子弹得更慢。卡琳娜站在墙边，鞋尖跟着地板上的光斑挪。埃利奥特走过来的时候，她一眼看出他在数拍子。

“你会跳吗？”她问。

“会在第三拍踩到别人。”

“那先别找别人。”她退开一步，“看着我脚下这条线。地砖的缝，不会跑。”

他们隔着一把空椅子练。他踩错了，她不停下纠正，只让下一拍照常来。转了几圈，他把空椅子推到墙边。两个人还是没有牵手，站得却比在谈话室里近。她开衫的袖口擦过他的手背。

“你没在数。”卡琳娜说。

“刚才踩准了，我在得意。”

“就是因为你不数，才踩准了。”

琴声停了，两个人还顺着惯性往前走了半步。她扶住椅背，他抬手要扶，她已经站稳了，却没有退回原处。她把额头轻轻靠在他的肩上。刘海被汗打湿，蹭着他的衣领。她笑过以后的呼吸还没平下来，他也没有动。

“要是我们在别的地方见面，”她问，“你还认得我吗？”

“认得。”

“头发剪短了呢？”

“我认得你的声音。”

“梦里也会有人用我的声音说话。”她抬起头。他正看着墙上那面镜子；她没有跟着去看，只看他。“要是脸也不像现在呢？”

他没有马上答。

“我可能不会第一眼就认出来。”他说，“但我会再看。”

她听见了中间那一下停顿，手还搭在他的肩上。她没要他把这句改成保证。

那天晚上，她在记录册的第三栏写：今天他在。看了很久，又在旁边补了一句：我也在。两句话分量不一样，她知道，暂时不想删。

那天活动室最后一排有人把纸盒碰翻了，卡片撒了一地。卡琳娜先蹲下去，帮那位年纪大的女人按颜色分。埃利奥特站在琴边，正要过来，见她们已经商量起哪一张该放最上面，就把手收了回去。

卡琳娜回头，看见他还在看。“你不会连这个也想记下来吧？”

“我只是在等你。”

“我还得把盒盖找出来。你先去吃饭，不用守着。”

他答应了，走到门口又回头。她已经和那个女人一起笑起来了，没有停下手里的事。

晚些时候她在食堂找到他，手里拿着那只纸盒的盖子，像拿着一件不值钱的战利品。她在他对面坐下，告诉他盒子里有三张卡片根本不是一套的，所以她们俩才一直分不对。他没问她为什么让自己先走。他听她讲完，把自己盘子里的面包掰了一半给她。

＊

后来，他们开始在暖气片底下那块松动的铁盖旁留纸条。有时会面临时取消，有时埃利奥特要去观察室，谁先经过谁就留一句。第一张是他写的：今天没有帮任何人，但长椅上的冰化了。

卡琳娜回：恭喜长椅获救。

不是每张纸都这么轻。有一次他把纸放回原处，上面一个字也没有。她等到晚上，开始想他们是不是已经被要求不许再见。第二天他来了，说自己不知道该写什么，怕写“我在”像一种保证。

“可你把空白放回来了。”她说。

“你会知道我来过。”

“我也可能以为是我忘了写。”

“那下次我画一道线。”

卡琳娜把那张空白纸折成四折。“不用。我昨天生气，不是因为没看见字。是因为你明明到了这儿，却没坐下来等我。”

他想解释是值班员把他叫走了，又觉得解释补不回她等过的那个下午。他问，下次要是只能留几分钟，她愿不愿意让他直接站到谈话室门口找她，而不是先写纸条。她答应了。下一次她看见暖气片底下空着，起身就去了谈话室门口。

又有一次，他迟到了二十七分钟。卡琳娜没有坐在暖气片旁边，怕别人看见她盯着那块铁盖的样子，就坐在院子的树底下剥一只橙子。她剥得很慢，想让橙皮连成一整条。剥到最后一瓣，他才从东区的门里出来，袖子遮不住左手腕上一块新的淤青。

“你去哪儿了？”

“观察室。”

她把一半橙子递过去。“我不是问你进了哪间屋。我问你为什么迟了。”

他接过来，没吃。“早上跟一个护工争了几句。她说我应该去看看自己是怎么睡觉的，别老盯着别人。我当时觉得她没资格这么说。后来才发现，我昨夜又在隔壁床边站了很久。”

“她说得不全错。”

“我知道。所以没来得及在纸上画线。”

卡琳娜咬下一瓣。“你真以为我要你每次都准时到，才知道你也有自己的事？”

“我以为你会怕。”

“会怕。可我也能听你讲为什么迟。”她看他终于吃了一瓣，才接着说，“你什么都不讲，那二十七分钟我会自己填满。有的是梦里见过的，有的是我编的，哪个都没你刚才讲得准。”

他把一瓣带着白丝的果肉留在掌心，好像一时忘了怎么咽。

他们把剩下的橙子分完，橙皮在铁盖旁边卷成一个不太圆的圈。路过的工作人员以为他们在做手工，提醒走之前把皮扔了。卡琳娜先笑出来，埃利奥特把橙皮捡进了垃圾桶。晚上点名的时候，两个人的指尖还是同一种味道。

那天夜里，卡琳娜又在梦里醒了一次。窗台上的杯子和她记得的位置不一样。她先数手指，然后去叫夜班护士。护士替她打开门，门外是熟悉的走廊；护士也替她念了今天的日期。回床的时候，她还是想去找埃利奥特，可她没去敲东区的门。护士念的日期她并不全信，只先记进记录册，等早上再对。

＊

她把判断自己是否醒着的办法写在一张松散的白纸上，是为了对付最近越来越多的假醒。那天下午她在谈话室里写，埃利奥特坐在旁边，一边把纸杯挪开，一边看她列出六条：同一句话读两遍；数手指；看钟；回想自己是怎么进屋的；看镜子里的动作对不对得上；打开门，核对门后面的空间。

“这些不一定都管用。”他说。

“我知道。它们能让我先停一下，别急着决定自己在哪一层。”

写完六条，笔在第七行停了很久。埃利奥特起身去还水杯。等他回来，纸上多了一行：埃利奥特在。

“这一条呢？”他问。

“也不是证明。”卡琳娜把笔帽扣紧，“有时候我醒过来太害怕，连钟都不敢看。要是能找到你，至少我会记得先跟你说一句话。”

他没有反驳。

出门的时候，她把这张纸夹进他的软皮本：“我回房可能就找不到它了。明天见面你还给我，我要抄进自己的记录册。”他当着她的面合上本子，放进外套口袋。两个人都知道纸在谁手里。

第二天下午，她照约定要回那张纸，看见第七行被涂成了一道黑。墨划得很重，纸背都透了过去。她没有马上问，先数了一遍前六条，确认一条也没动，才把本子推回他面前。

“你为什么只划这一条？”

他看了一眼那道黑。“因为有一天我可能不在。那不该变成你判断自己还在不在的理由。”

“我写的不是‘你能证明我醒了’。”

“我昨晚一直在想，你会拿它去证明。”

“所以你替我改了？”

她问得很轻，他没法把这当成一场字面上的争执。他把本子拿过去，承认自己应该先问她。

“我也不知道真找不到你的时候，我会怎么样。”她说，“写那一句，是因为我们见过那么多个下午，你有时候能先让我坐下喝口水，而不是马上追问这一切是真是假。”她停了一下，“我没想让你保证明天。我想把今天留下来。跟那架破钢琴一样。”

他的手停在书脊上。

“我划掉它，不是说我今天没来。”他说，“是我怕你有一天找不到我，会连今天也一起不要了。”

卡琳娜没有原谅这次擅自的涂改。她把纸从本子里抽出来，沿着那道透墨的折痕重新折好，夹进自己的记录册。

“下次先问我。”

“好。”

他们没有为第七行重新写一个对的答案。广播响了，卡琳娜把记录册收进怀里。埃利奥特走在她旁边，没去牵她，也没故意拉开距离。他们沿着洗衣间旁边的服务走廊，走过三扇门，最后是一段白墙。她走过去以后回头看了一眼。他还在那里，她才接着往前走。

- **视角**：本章是全书第一次完整进入卡琳娜的意识，全章贴她，不再进入埃利奥特的内心。
- **事件顺序**：只谈天气、长椅结冰 → 活动室鸟 → 童年厨房放鸟、火灾、“随后就来”、“到” → 假醒的来源 → 门边长椅、“你现在不用去证明” → 三栏记录册、第三栏第一次写名字 → 空床、右手按左腕、冰台阶 → 走调钢琴、华尔兹“第一拍”、靠肩、“别处相认”之问 → 卡片与纸盒盖 → 暖气片纸条、空白纸、二十七分钟、橙子 → 夜里向护士求助 → 六条清醒判断＋第七行“埃利奥特在”→ 次日见第七行被涂黑 → 服务走廊三扇门与白墙。
- **伏笔**：鸟第二次出现，揭出来源；华尔兹三拍是她与病症无关的私人快乐；折纸进入暖气片阶段；第七行被涂黑后，纸收进她的记录册，第八章她在这张纸的背面写最后留言；三扇门与白墙。
- **信息权限**：不提酒店、凶案、1814；“死亡即醒来”只以她咽回去的那个问题出现。

### 二、视角越界的处理

- 原稿“她说的是长椅。埃利奥特听懂了明天。”在卡琳娜视角中写了他的心理，改为“他点头的样子，像听见的是明天”。
- 原稿华尔兹段“他在谈话室见过她把折纸压得整齐的样子……”是埃利奥特的内心，删去。
- 原稿纸卡片段他“感到宽慰，胸口又有一点难以启齿的空……”删去，改为她看见的动作：他走到门口又回头；在食堂把面包掰一半给她。
- 原稿第845行他夜里去听隔壁呼吸、涂黑第七行，是埃利奥特视角，删去整段。涂黑这件事改由卡琳娜第二天看见，原因由他在对话里说出（“我昨晚一直在想，你会拿它去证明”），信息一项未少。时间线 v5“次日被他划掉”不变。

### 三、删去的解释句

合集第679、691、733、781、783、801、823、827、841行，按诊断清单处理。其中第823行改为只留“他把一瓣带着白丝的果肉留在掌心，好像一时忘了怎么咽”，第801行改为她下一次直接去谈话室门口找他。

### 四、与正典对齐（文字层面）

原稿写她“成年以后搬过几次住处”，与正典冲突：正典规定她18岁起一直处于司法精神机构，“漂泊”是机构之间的安置，不是成年后自己搬家。现改为“十八岁以后，住处换成了机构：评估、安置、再评估……从来没有一把属于自己的钥匙”。第六章的同类句子同步修改。

### 五、意境

本章主导意象是**三拍**：钢琴慢半拍的琴键，地砖缝那条“不会跑”的线，第三拍踩脚，“就是因为你不数，才踩准了”。章题“第一拍”由此落地。辅助意象是橙子（连成一条的橙皮、指尖同一种味道）。

### 六、对白

本章原稿对白质量较高，绝大多数只做口语化压缩，意思不变。

| 原句 | 现句 | 原因 |
|---|---|---|
| “今天我们可以只谈天气。你不需要把每件事带回我的梦里。” | “今天只谈天气。不是每件事都得绕回我的梦里。” | 她的声线 |
| “它不是一本能把我判定清楚的病历。” | “这不是一本能把我判清楚的病历。” | 口语 |
| “你为什么要保留那些看似互相矛盾的醒来？”（原为间接叙述） | “这些对不上的醒来，你为什么都留着？” | 改成直接台词，读者更清楚 |
| “会。” | “认得。” | 与问句“还认得我吗”对应 |
| “如果你什么都不讲，我会把缺的那二十七分钟填满很多事……” | “你什么都不讲，那二十七分钟我会自己填满……” | 收短 |
| 涂黑第七行后的争执 | 她原本由叙述转述的话改为直接台词（“我也不知道真找不到你的时候，我会怎么样……”） | 视角改为她，原转述不再成立 |
