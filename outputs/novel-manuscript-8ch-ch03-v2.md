# 第三章　先证明我在

那张纸一直在埃利奥特的外套口袋里。早上换衣服，纸角从衣缝里露出来，他按回去，没有抽出来。写着“维多利亚”和“1814”的那一面贴着布。他不想交给卡琳娜，也舍不得扔。

下次见面，卡琳娜没提少了的那一页。她带来两只纸杯，一只放在自己面前，一只推过桌子。杯口的接缝朝着窗。第一天他就是这么摆的。

“我说过的话，你没忘吧？”她问。

“你醒了几次那件事？”

“你手上那道伤。你说想起来了会告诉我。”

他以为她不会再问了。那天她给他留了退路，他就把退路当成了这件事已经过去。

“我进过一栋废楼。”他说，“出来以后，有些事记不清了。手是在里面划破的。”

“酒店？”

“以前是。”

卡琳娜低头看杯里的水，等着。

“有块门牌掉下来，割的。附近有家便利店，老板替我叫了人。”

“他认得那栋楼？”

“他只说那里着过火。”

“别的没问？”

“问了。他不知道。”埃利奥特顿了一下，“我不是在查你。那次进去，是认识你以前。我自己也不知道为什么会在那儿。”

卡琳娜抬起眼。两个人都碰过那四个数字，她脸上没有一点高兴。她看他看得比平常久，是在他说“我自己也不知道”的时候。

“那你为什么一直像在替我核对？”

“因为我也记得一栋楼。”他把杯子往自己那边挪了挪，“你的房间，我的楼，我想分开放。混在一起，我们就会拿一个去证明另一个。”

“这句不像从书上抄的。”

他本想问以前那些像不像，最后只是把本子合上。缺了一页的那道白茬正好露在封面外面。卡琳娜看见了，只说：“下次你不想答，就说不想答。别先说没有。”

他想起自己对她说过很多次“不记得也没关系”。那句话他说得太顺口了。

＊

后来的谈话慢了下来。埃利奥特还是记，但先把写下的字转给她看。有一次，她把“困在房间里的女人”划掉，改成“我看见她坐着，不知道她是不是被困住”。另一次，她把“屋顶坠落”改成“记得往下掉，不知道从哪里开始”。他没有争。字改过了，维多利亚还是坐在那间屋里，卡琳娜的梦也没有轻一点。只是她改完字，把本子推回来的时候，力气比以前小。

有一回，她把本子转向他，指着页边一排短短的竖线。埃利奥特自己都没注意过：门外每过一辆推车、每有人喊一声，他就停笔，在空白处划一道，再接着写。

“你在等什么？”她问。

“不是等。听见声音，总想知道是谁。”

“你写我的话的时候，也在听别处。”

他想说这不耽误他听清楚。她已经把纸从他面前抽过去，在自己那一页的边上也划了一道。

“你说要把对不上的地方都留着。”她说，“你说你在认真听，我又看见你走神。这两件事也可以都留着。”

他看着她划的那道线，有种被人反过来记了一笔的不舒服。卡琳娜没有得意，把本子还给他。

“我不要你解释。你听见动静会不安，告诉我一声就行。下回你突然停笔，我就不用以为是我说错了话。”

他答应了。后来门外再有推车，他还是会看过去，但先说一句“有人走过”，再等她接着讲。

＊

停电是在五天以后的下午。

风把窗外的铁网吹得轻响。卡琳娜拿一张旧通知裁成几块，在桌上排出梦里那个房间：大块的是床，窄纸条是窗，压在杯垫底下的是门。埃利奥特没问是不是1814。他把本子转向她，让她看清自己画的平面。

“门在这儿。”卡琳娜说，“我醒了以后，记得有人敲过它。”

“你在门里还是门外？”

“我以为在里面。”她把窄纸条往外挪，“可要是那声音是从楼梯上来的，我可能还没进屋。”

他伸手按住纸条。她的手指还搭在另一头。两个人的指尖隔着一张薄纸，谁都没先拿开。

“怎么敲的？”

卡琳娜在桌上敲了三下。她没看他的脸，又敲了两下，像替前面三声把话说完。

桌面轻轻一震。他先闻到一股潮湿的灰味，像有人把旧楼的墙皮剥下来，铺进这间干净的谈话室。头顶的灯闪了一下，又闪一下。窗外有人叫了一声，走廊的日光灯一起灭了。

“备用电很快就来。”卡琳娜说。

他听见了她的话，也听见工作人员在门外喊大家待在原地。可红色应急灯一亮，谈话室右边那面墙忽然显得很深。桌边一道旧擦痕往上长，长成一个被火烤过的门框。门框后面是楼梯，扶手一路转下去。拐角处有一只苍白的手，离他不过几步。

他知道站起来会吓着她。椅子已经被他撞开了。上次他在楼梯上放弃了那个声音；再等下去，拐角的人也许会像很久以前的那个人一样，连一句完整的话都来不及说。

“埃利奥特？”

卡琳娜拽住他的袖口。他想甩开，低头却看见自己的右手正伸向一片平平的墙。墙上的黄铜扶手又浮出来，这一次他差点摸到。

“那里没有门。”卡琳娜说，“你先别过去。”

“下面有人。”

“我没听见。外面也没人往那边走。先退回桌子这边，好吗？”

“要是有呢？”

“那我们叫值班员一起看。”她没说他疯了，也没说那声音不存在，“可你现在离墙太近，灯还没来。你扶一下桌子，我去叫人。”

他不肯离开那面墙。卡琳娜就把他的右手拉回桌沿，按在木头上那个缺口旁边。掌心的旧疤正压着缺口的边。疼从一个确实存在的地方升上来；楼梯上那只手没有。

“桌上还有什么？”她问。

“纸。”

“几块？”

“床，窗，门。”他摸到两只纸杯，“还有水。”

“我呢？”

他抬起头。她的薄刘海被额头的汗粘成一绺，左边嘴角下那颗浅痣也在。他认出了她。他太想她在这儿了，想得不敢信。

卡琳娜看出他还在犹豫。“墙后面是什么，你可以不信我。先确认我站在你面前，刚才把纸摆在桌上。别的等灯亮了再看。”

她松开他的手，朝门外喊值班员。他一个人按着桌角，没有再往墙上摸。走廊的灯一盏接一盏亮起来，那道擦痕缩回靠近地面的地方。墙纸、扶手、那只手，都不见了。桌上还是她摆的那个房间：窗，床，门，少了一块纸。门从来没有长到墙上去。

值班员进来，先看两人有没有受伤，再把椅子扶正，说备用电已经接上，谈话室暂时关闭。

“卡琳娜，西区十二床。埃利奥特，东区九床。现在回病区点名。”

她念两个床号，用的是同一种声音。埃利奥特一时没动。值班员从口袋里掏出两只小药杯，一只递给卡琳娜，另一只放在他面前。

“你的药晚了十分钟。”

埃利奥特盯着药杯。值班员等他喝完水，才把借给他的圆珠笔收回去。她脸上没有失望，也没有等他解释的意思，就像催任何一个迟到的人回去那样，又说了一遍：东区九床。

卡琳娜先走到门口。埃利奥特终于问：“你第一天就知道？”

“知道我们住在同一栋楼里。”她说，“第一次见面，门口的人念过两个名字。你在翻本子，大概没听见。”

“为什么不告诉我？”

“我以为你不想谈你自己。”

“可我一直在问你的事。”

卡琳娜把手从门框上拿下来。“是。我也一直在答。今天你肯说那栋楼，已经比以前多了。”

她没有笑他。埃利奥特反倒更想躲开。

＊

东区九床的柜子里，埃利奥特把软皮本放在一叠洗干净的衣服上。那是他自己买的普通本子，封底已经翘了。里面除了卡琳娜的梦，还有他这几个月记下的街名、夜里醒来的钟点，和一张折了很多次的便利店收据。他从没叫它病历，她也没问过它是不是。

他想起第一天值班员在门口念了两个名字。他在找空白页，后半句确实没听进去。她早就知道他的床号，也知道借来的笔要还回值班台。她从来不是被他骗住的那个人。她知道这些，还是每天下午来，还把他写错的字改过来。

第二天上午，管公共谈话室的护士找他问停电的事。她不怪两个病人在开放时间里谈话，只提醒他，那间屋从来不是治疗室，值班员核对名字，只是确认两边都同意借用。埃利奥特说他知道。护士问他有没有对卡琳娜说过自己是医生。他说没有。

“可你把谈话安排得很像一次治疗。”护士说。

“她愿意说，我就问了。”

“她也会听你说吗？”

埃利奥特想起前一天自己伸手去摸墙，是卡琳娜先让他摸到了桌角。他没答。护士没把这个停顿当成答案，只说他要是还想见卡琳娜，下次先问清楚，她愿不愿意用现在两人都知道的身份接着谈。

出门时，他看见墙上贴着谈话室的开放时间，底下一行小字：双方可随时结束。这行字一直贴在那儿。他用“今天先到这里”结束过很多次谈话，卡琳娜很少先起身。他在那行字前面站着，一直站到身后有人要过。

＊

此后三天，他没有去谈话室。

第一天，他在院子里走了很久，鞋尖沾满化雪后的泥。

第二天，他看见卡琳娜站在饮水机旁边，转身拐进了另一条走廊。走出很远他才想到，她未必在等他。手里那杯水，他一口也喝不下去。

那天下午东区有例行的小组谈话。工作人员请每个人说一件今天愿意做的小事。轮到埃利奥特，他说想整理本子。有人问那本子是不是写给他自己的，他答不上来。他记得别人什么时候手抖，记得谁说过哪一个梦；翻到写自己的那几页，只有地点和日期。

回房以后，他把藏在口袋里的那张纸拿出来。折痕已经软了，数字还很清楚。他没有把它贴回本子，也没扔。隔壁床的人见他盯着看，问是不是地址。他说是一个房间号。对方问他打算去吗。他摇头。他已经去过一栋楼，连怎么进去的都没找回来。想再去一次的念头刚冒出来，他就把纸收好，走到窗边，看工作人员扫院子里的路。

第三天下午，他在公共区看见卡琳娜在那张桌子边坐了一会儿。她没用别人给他空出来的那把椅子，也没把两只杯子摆回从前的位置。广播一响，她自己起身走了。他站在原地，先觉得失落，接着又为这点失落脸上发烫。

那天夜里，他半睡半醒，以为隔壁床的人没在呼吸，差点把对方摇醒。对方翻个身骂了一句。他回到自己床边，坐到天亮。

＊

第四天下午，谈话室重新开放。卡琳娜坐在窗边折一张纸，没有把空椅子挪到身边。埃利奥特站在门外，先确定她看见了自己，才走进去。

“我以为你不会来了。”她说。

“我也这么以为。”

“来为停电的事道歉？”

“一部分。”他把椅子搬过桌角，停在她旁边，没坐，“我想告诉你，我不能再像以前那样问你了。停电那天，那间屋里有什么，你比我清楚。”

卡琳娜把纸折齐。“你以前也不用什么都清楚。”

“那我可以坐这儿吗？”

“椅子是公用的。”她看了他一眼，“可你坐下以后，不许再把我的梦当一张等着填满的表。”

他没马上坐。“停电那天，你也很怕。”

“我怕你冲到墙上去。我还怕我一靠近，也会跟着你看见那扇门。”卡琳娜把纸折到一半，手指停在折痕上，“我把你的手按到桌边，自己也摸到了木头，才敢喊值班员。不是我站在一个什么都看清的地方，把你拉回来。”

“我当时以为你很确定。”

“我只确定桌子在那儿，你的手在我手里。灯亮以前，墙后面有没有东西，我也没法替你证明。”

埃利奥特点了点头。那几分钟，他一直记成自己失控、她镇定。原来那时候，两个人手里都只有一张桌子。

他坐下了。没带本子，也没带笔。窗玻璃上还留着第一天鸟撞出来的灰痕，淡得快看不见了。卡琳娜接着折纸，折到第三道停住，把没折完的那一面朝他放下。

两个人谁也没说现在算什么。广播催人离开时，他先站起来，又等她把那道纸折完，才一起出门。

＊

第二次不带本子见面，他们沿着院墙走了半圈。没有本子，他不知道该从哪儿开头，只好说自己昨晚没睡好。说完又怕这像在讨照顾，赶紧补一句“已经没事了”。

卡琳娜没让这句话就这么过去。“你是想说为什么没睡好，还是只想让我知道你没睡好？”

“后一个。”

“那我知道了。”她把围巾往上拉了拉，“我昨天也没睡好。不是因为你走了三天，你不用担这个。可你回来了，我今天走得比昨天远一点。”

埃利奥特往前看，才发现他们已经走过了第一道栅栏。以前在这条路上，他总在算走回屋里要多久。这一次，他只记住了她说“我也没睡好”时的口气，平平常常，像在说天气。

## 改动说明（不属于正文）

### 一、本章不能动的东西（已逐项守住）

- **事件顺序**：他向她讲出废楼和便利店（老板只说着过火，发生在认识她以前）→ 两人改写记录、页边竖线的约定 → 五天后停电：纸片摆出房间、她敲三下＋两下、他错认墙上的门框和楼梯、她把他的右手按到桌沿缺口、“桌上还有什么”“我呢”→ 灯亮，值班员报床号、递药杯，病友身份揭晓 → 第一天念过两个名字 → 护士谈话、“双方可随时结束”→ 他缺席三天 → 第四天回来坐到她身边，不带本子 → 沿院墙散步。
- **伪治疗关系的揭晓方式**：由工作人员对两人做同样的制度动作揭晓（同一种声音报床号、两只药杯、收回借来的笔），没有一句台词把机关点破。
- **信息权限**：便利店老板只确认火灾；停电时的门框、楼梯、黄铜扶手只是他的错认。
- **伏笔**：杯口接缝朝窗（接第一章 v4）；三下＋两下；黄铜扶手（接第一章大厅闪回、指向第八章裂缝）；第一章念两个名字（接第一章 v4 新补的接口）。

### 二、按“关心循序渐进”调整

本章是关心第一次失去职业外壳的一章。身份揭晓前，他在停电中的失控是他自己的创伤；揭晓后，他的关心没有了“引导者”这个借口，于是他躲开三天。这一章只写到他回来、坐下、不带本子为止，不提前写依恋。新增了一处可回看的公平线索：缺席第三夜，他以为隔壁床的人没在呼吸。它接第一章 v4 他看她领口起伏的那一眼。

### 三、按诊断清单处理的条目

- **删去解释句**（合集第449、459、475、555、559、571、579、605、617行）。其中第555行“那本软皮本和借来的笔没有让他成为她的医生，只有他自己始终试图让两人坐在那样的位置上”整句删去，回看交给读者。
- 第571行的心理结论，换成他站在“双方可随时结束”那行字前面，一直站到身后有人要过。
- **存疑第5条（“像姐姐一样”）**：按推荐改为“像很久以前的那个人一样”，“姐姐”二字留到第五章。
- **缺席三天的时间顺序**：原稿“第三夜”写在“第二天”之前，读者容易乱。现在按第一天、第二天（含小组谈话和撕下的那页纸）、第三天下午、第三天夜里排列，内容不增不减。

### 四、意境

本章主导物件是**桌沿的缺口**。停电时，他掌心的旧疤压住缺口，“疼从一个确实存在的地方升上来；楼梯上那只手没有”；回来以后，她说“我只确定桌子在那儿”，他想到“两个人手里都只有一张桌子”。辅助意象是灯：先闪两下，接着红色应急灯，最后一盏接一盏亮回来。
