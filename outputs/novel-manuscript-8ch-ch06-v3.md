# 第六章　同时

转院通知是星期二上午送到的。

文件上说，卡琳娜后天离开，去一家更远的医院继续治疗；探视和通信要重新安排。她读完第一页，问能不能先去拿她的记录册。工作人员说，会有人陪她收拾东西。她又问，埃利奥特知不知道。对方没回答这个问题，只说今天不能见面。

签字的时候，笔尖在纸上停得太久，洇出一小团墨。十八岁以后，她被安置过一处又一处，东西总是收得很快，却从来不能决定钥匙什么时候被别人收走。这家医院至少给过她一扇固定的窗、一面钟、一条能走到活动室的路。现在连这条路，也要别人来告诉她什么时候停。

她的记录册里夹着一角发黄的旧报纸，只剩“火灾”两个字和酒店的地址还认得出。她从不把它当证据。关于十二年前那一夜，别人告诉她的，比她自己记得的多：有人说她从一个较低的屋顶掉下来，被雨棚和一辆装旧床单的车接住了；有人说她手里攥着一把不属于她的钥匙。她记得往下掉，记得白布压在身上的重量，却分不清这些画面是那天夜里的，还是后来一遍遍听人讲出来的。她也听过比火灾更可怕的说法。问到凭什么，每个人都说自己只是听说。

醒着的时候，她能说“我没有伤害别人”。夜里，她却梦见自己站在别人死去的房间里。两种记忆都有手感，不能看哪一种说得更平静就判哪一种对。

午后，她被带去清点私人物品。折纸还装在透明袋里，记录册最后一页没被拿走。她翻到“同一层”“同时”，看见自己把两个名字写得太近，轻轻把本子合上。后天以后，很多话就再没机会当面问了。

＊

埃利奥特在东区听到消息，先去值班台问能不能给她留一封信。值班员说可以代转，要先登记。他在纸上写了几行，写到“你可以先去”时停住了。他想让她活着离开，却没法把这句话写得不像在替她做决定。最后他只写：你上次问长椅怎么样。今早我去看了，冰化了，已经能坐了。

想到她也许明天早上就坐不上了，他把纸揉进掌心，没有交出去。

他又跟值班员要接收医院的地址。地址还没公布，值班员让他等手续办完，先写明想寄给谁。他拿着那张表，“收件人姓名”很好填，“双方关系”那一栏却填不下去。他们不是医生和病人，也不是亲属。他不肯让工作人员替他们挑一个词，把表格叠好放进了口袋。

晚饭前，两辆洗衣车停在东西区交界的走廊上。工作人员忙着把旧床单送去洗衣间。埃利奥特听见车架上轻轻响了三下，接着两下。声音被轮子的动静盖住了，只有他停了脚。他跟着车走到收发室旁边。垂下来的白床单后面，卡琳娜站着，肩膀贴着铁架。

“你怎么出来的？”他问。

“我说想自己去拿记录册。”她看了一眼他手里捏皱的纸，“你也没待在该待的地方。”

走廊另一头有人说话。他们躲不了多久。他本想告诉她自己会申请探视，开口却问：“东西收好了吗？”

“还没有。你会说什么，我还不知道。我不想先把我们在这儿的东西全折进箱子里。”

“我会想办法给你写信。等他们定下探视——”

“你总说‘等’。”她看着他，“我能等一个日子。可我不知道下次见你，你还在不在我记得的那个地方，还是他们已经告诉你别再来了。”

“我没答应他们不再来。”

“你也没答应我一定会来。”

他没有给出保证。他怕保证落空，就像他涂掉第七行的时候那样。

卡琳娜从开衫口袋里拿出一个折好的纸包，平放在两人之间的床单上。

纸里是药。是她这些天瞒着查房，一粒一粒攒下来的。

她没有递给他，只让他看见。

“我想过别的办法。”她说，“转院，写信，甚至你来找我。每一种，都得有一个人先醒，一个人在那边等。”

“你攒这些，是想让我们谁都不用等？”

“如果死真的是醒到别的地方去，”她的声音一点没抖，“为什么每次都得我一个人去？你见过我从不可能的地方醒过来。你自己也有过，明明走进了一栋楼，却不知道是怎么进去的。我们没有证据，证明那只是病。”

“也没有证据，证明一起死就能去同一个地方。”

“那至少我们可以同时做一次。你不用先替我去看门，我也不用老等你来告诉我，这里是真的。”

埃利奥特看看纸包，又看看她。她解释得这么仔细，不是要吓他。

“我知道转院让你害怕。”他说，“你可以怪我没拦住他们。可这件事，不能拿我们的命去证明。”

“我不是要证明给他们看。”

“也不能证明给我们自己看。”

“你又在替我决定什么是真的。”

他想起服务走廊里那三扇门。这一次，他不能再拿一句顺着她的话把她带回去了。上次他用一句谎话留住了她；这次再顺着说下去，代价就不是一面墙了。

“你经历的每一次醒来是什么，我不知道。”他说，“我也承认，我在那栋废楼里见过一些东西，醒着的时候说不清。可纸包里那件事，只有一个后果我敢确定：我们可能再也见不到了。你怕被留下。我也怕。不能因为怕，就把再见的那一点可能也一起毁掉。”

“你还是觉得这里比别处真。”

“我没这么说。我只知道你现在站在这儿，还能跟我吵。我想让你明天也能这么站着。”

卡琳娜把目光移开了。过了一会儿，她问：“要是我去了另一家医院，还是相信要醒就得先死，你会怎么样？”

“我会去听你说。”

“听完呢？”

“我可能还是不同意。可我会尽量让你知道，我不同意的，不是你受的苦。”

她看了他很久。“你做得到？”

“我只能说我会去。你可以不信。”

她还是没把纸包收回去。他也没伸手去抢，只问她：今晚要是不做这件事，明天她最怕的是什么。

“我会坐上一辆车。”卡琳娜说，“车开走了，你在这儿接着过几天。一开始，你还记得我是哪天走的。后来，我在你那儿，就只剩一个要处理的故事。”

“你不是我做过的病例。”

“我知道你不是医生。”她盯着他，“可你还是喜欢把我放在一张能写完的纸上。”

他承认她说对了一半。他也怕自己以后只记得一个被救过的卡琳娜，忘了她在活动室笑他踩错拍子，忘了她在服务走廊逼他承认撒了谎。他一件一件说这些具体的事。她一直看着白床单，指尖却从纸包边上挪开了一点。

几乎。她几乎要把纸包收起来了。

她记得很多次跟母亲的分开，也记得母亲说随后就来。

“你以前也说过，你能守住一个人。”她说。

埃利奥特的右手按住了左腕。

＊

姐姐比埃利奥特大九岁。父亲走了以后，是她送他上学；他夜里说门后面有人，是她拿着手电，陪他一扇一扇去看。那时候他相信，她看过的地方就不会出事。

过了几年，轮到姐姐不敢睡了。她说电话线里有人在听，水杯可能被人动过，连最熟的屋子也开始有她不认识的角落。埃利奥特替她锁门，换杯子，检查窗户。他做得越熟练，别人就越相信姐弟俩自己应付得来。邻居说要帮忙找医生，他也拒绝过，怕陌生人让姐姐更不安。他以为，只要自己一直醒着，她有危险的时候他就能听见。

那天晚上，姐姐坐在床边，脚底下散着药，水杯翻了。她说她只是很累，不想再让人进屋。他把看得见的药收好，坐在床边听她呼吸。她问他会不会走，他说不会。他听着她慢慢安静下来，以为最难的那一阵已经过去了。

天亮的时候，他的额头压在自己的胳膊上。他不知道自己睡了多久。姐姐的手还在他手心里，已经凉了。救护人员来了，问他为什么不早点打电话。他的第一个回答是，姐姐不愿意。第二个回答是，他以为能等到早上。后来很多年，这两句话他轮流想起来，哪一句都没能让她回来。

后来他搬了好几次家，每次只带同一个小箱子。箱子里有一只姐姐年轻时用过的圆口杯，他从来不拿它喝水；还有一张写着旧地址的纸，他也没扔。新住处只要开始像个家，他就会在某个夜里醒来，摸到床边没有另一个人的呼吸，然后穿上外套出门走路。走到不认识的街上，再自己找回去。

他后来也明白，那时候他太小了，那件事不该由他一个人扛。明白了，也拦不住他每次醒来先去听身边人的呼吸。卡琳娜说“同时”。他看见的不是两个人找到同一扇门，是总有一个人，会因为另一个人消失，再醒一次。

＊

一阵风把白床单吹起来，贴在埃利奥特肩上。卡琳娜没有再问姐姐的事。她看见他不肯碰那个纸包，已经知道那段记忆把他带去了哪里。

“我不是她。”卡琳娜说。

“我知道。”

“你要是因为当年没救成她，才不肯跟我走，我可以等你不那么怕。”

“我怕，是因为你可能会死。”他把床单从肩上推开，“就算从来没有她，我也不能答应。”

她的手指停在纸包边上。

“我想见你。”他说，“哪怕我们再也坐不到同一张桌子旁边，我也想你有以后。你要是恨我替你这么说，就恨吧。”

“你宁愿我在别处活着，再也不见你？”

“不是宁愿。我会想办法见你。”

“要是他们不许呢？”

他看得出她在等一句“那就一起走”。他没有说。

“那我也不愿意拿你，去换一个我没法确定的地方。”

卡琳娜往后退了一步。

“我现在很想让你闭嘴。”她说。

“我知道。”

“我也不想看见你躺在这里。”

她把纸包塞进他手里。他下意识接住，摸到纸里硬硬的东西，五指一下子张开了。纸角松开，几片白色的药滚进铁架底下。两个人同时低头。谁也没去捡。

“要是我明天在另一家医院醒过来，你还在这儿呢？”她问。

“那我还活着。”他说，“你也活着。我们至少还能试着去找。”

她抬起手。指尖停在他的脖子侧面。

隔着很薄的一层皮，她摸到了他的脉搏。很急。

他没有往后退。胸口跟着她手指的停顿，起伏了一次。

脉搏还在跳。他没躲，也没改口。

卡琳娜把手移下去，替他按平了翻起来的衣领。

外面响起脚步声和钥匙声。洗衣车被推开，工作人员掀起白布，看见床单上的纸，也看见了铁架底下的药。有人叫他们退后，蹲下去收拾。卡琳娜没有争，也没替自己解释。埃利奥特这一次也没替她瞒。

两个人被分别带回病区。走到门口，卡琳娜回了一次头。埃利奥特想叫住她，告诉她自己刚才写了一封信，纸还在手里。她已经被护工带出了他的视线。那封没交出去的信，还攥成一团。

＊

卡琳娜回到西区，要求拿回记录册。护士先看她能不能安静坐下，才把本子给她。她翻到写着“同时”的那一页，想把这两个字划掉，笔停在上面，迟迟没有落下去。被带走的时候，她最先担心的竟是：他今晚会不会又守着墙，一夜不敢睡。笔尖在“同时”旁边停了很久。她没有划掉它，也没有再往下写。

＊

入夜以后，转院提前到了第二天清早。

埃利奥特被安排进东区观察室，门外有人守着。他知道同意观察，是为了不让卡琳娜的处境更坏。可他还是一次次在快睡着的时候撑起身子，怕自己一醒，她已经走了。

隔壁墙后传来三下敲击。

他说不准那是不是从西区传过来的，也说不准这么晚了，她还有没有机会靠近那面墙。他等了很久，才用指节回了两下。

那边没有再响。

最后，他攥着那封没寄出去的信，睡着了。

## 改动说明（不属于正文）

### 一、本章不能动的东西（已逐项守住）

- **事件顺序**：转院通知（后天离开）→ 旧报纸剪角、十二年前的传闻 → 清点物品、“同一层”“同时”→ 他写信未交、“双方关系”一栏填不下 → 洗衣车上的三下＋两下、白床单后见面 → 她拿出攒下的药，**现实共同死亡邀请** → 他拒绝 → 姐姐死亡回忆 → “我怕，是因为你可能会死”“就算从来没有她，我也不能答应” → 药撒到铁架下、她的手停在他颈侧、替他按平衣领 → **现实中她没有伤害他** → 被发现、分别带回 → 转院提前到次日清晨、观察室、隔墙三下他回两下 → 攥着信睡着。
- **信息权限**：旧案只来自传闻（“有人说……”“每个人都说自己只是听说”）和她分不清来源的记忆；无可靠来源证实凶案。
- **拒绝的根部**：他拒绝主要因为不愿她死，不是靠分析说服自己；姐姐回忆放在拒绝之后，作为根部，不作为理由。

### 二、诊断清单中的条目

- **问题 2 指代**：第1135行信里“你上次说长椅的冰化了”→“你上次问长椅怎么样。今早我去看了，冰化了，已经能坐了。”（第四章说冰化了的是他，问长椅的是她。）
- **存疑 7（按腕的手）**：第1213行“左手按上右腕”→“右手按住了左腕”，与第四、五、七章一致。
- **与正典对齐**：第1127行“她想起自己成年后换过的那些住处”→“十八岁以后，她被安置过一处又一处”（同第四章）。
- **删去的解释句**：第1131、1137、1169、1187、1199、1207、1225、1253、1267行；第1273行整段压缩为她握笔停在“同时”旁边的动作。
  - 第1131行“令她最羞耻的仍不是那把钥匙……”删去；保留同一段里“醒着能说没有伤害别人，夜里却梦见……”的可见对照。
  - 第1267行“她刚说过不愿看见他躺下，手却停在最容易伤害他的地方”删去，让脉搏与按平衣领自己成立。
- **问题 3 节奏**：对峙段在三个顶点改用短句、单独成段：药包摊开（“纸里是药。是她这些天瞒着查房，一粒一粒攒下来的。”“她没有递给他，只让他看见。”）；“几乎。”；颈侧脉搏（“很急。”“脉搏还在跳。他没躲，也没改口。”）。

### 三、视角

结构 v3 写本章主视角为埃利奥特。按作者确认的处理（只删越界句、不删场景），本章用分隔符把场景分开：开头转院通知与清点物品贴卡琳娜，章中被带回西区后一小段贴卡琳娜，其余全部贴埃利奥特。同一场景内不再来回进出两人的心。

### 四、意境

本章主导意象是**白床单**：洗衣车上垂下的床单、她站在后面的“白布”、纸包平放在床单上、风把床单贴到他肩上、工作人员掀开白布。它同时回响第二章她记忆里蒙在脸上的漂白水味床单、第八章她从白床单底下醒来。
