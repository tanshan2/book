# 第七章　一直是你

黄铜牌从手里滑出去的那一刻，埃利奥特想起来了：他是在东区观察室里睡下的。这段记忆来得太晚，没能让脚下的地板停住。他跌穿腐朽的楼板，落进下一层的宴会厅。左肩重重撞在一把翻倒的椅子上，头顶的灰落了很久。

他在碎木头里摸到手电，试着站起来。衣服扯破了，腿还撑得住。宴会厅的壁炉塌了一半，墙上露出烧黑的花纹。他记得朋友在街口等他，便沿着还能走的楼梯一路往下。侧门外只有空街。停车的地方留着两道湿车辙，车不见了。

他喊朋友的名字。街上没有回声。街角电话亭里的听筒没有拨号音。他往前走，绕过一个路口，酒店的正门又出现在面前，像他刚才那段路是绕着它转了一圈。天还黑着，雪还是没落下来。他不愿再上十八层，最后回到三楼一间还算完整的客房，用椅子抵住门，想等天亮再去找路。墙后响起三下敲击的时候，他已经太累了，只来得及摸了一下右手掌心的旧疤。

＊

再睁眼，房间里有暖气。

他坐起来。床头的电子钟变成了翻页钟，钟壳干干净净，窗台上也没有灰。他去挪抵门的椅子，才发现椅子根本不在门后。床头的服务册印着圣诞舞会的菜单，年份是一九八一。纸上还有油墨味。

他把服务册读了两遍，日期没变。门外先是有人跑过去，接着整层的灯都灭了。他站在黑暗里，听见楼下很多人同时在说话。他回想自己是怎么来到这个房间的，竟有两段都完整的经历：一段是朋友开车送他来；一段是他在这间没烧过的客房里住了一夜。后一段没有订房的过程，枕头却还是温的。等他扶着墙出门，已经没法凭身体分辨哪一段更真。

停电把住客都赶到了大厅。女经理和门房一边对着登记簿，一边点人，把楼上还没下来的也算进去：今晚困在这里的，一共十三个，五个是女人。厅里有挽着手的老夫妇，拿着撬棍的行李员，手上缠着布的厨房帮工，还有从各层下来的住客。埃利奥特先数通往街上的门：侧门锁着，正门的玻璃外面只有黑色的雨。

一个短头发的女经理从前台拿来一盏煤油灯。她告诉大家，电梯不能用，电话线也断了，最好先留在亮的地方。她说话的样子不像在扮镇定：她看过每个人的鞋，知道谁可能刚从楼梯上下来。埃利奥特觉得她的目光很熟，脸却认不出来。

“你在这儿工作多久了？”他问。

“够久，知道停电的时候哪条楼梯还能走。”女经理把灯放在柜台上，“你呢？我不记得今天给你办过入住。”

他答不上来。她的指节在木柜台上敲了三下，停住，又敲了两下。灯火晃着，那五声却清楚得像谈话室的桌面。他抬眼看她，她已经转向门房，问楼上还有没有没下来的客人。

有人说，十八层的1814刚才还亮过灯。

埃利奥特比谁都快地看向楼梯口。女经理叫他等两个人一起去，他已经拿起一支蜡烛上楼了。门房追到转角才赶上他。

1814的门没锁。一个年轻女人坐在床边，浅色外套扣得整整齐齐，鞋也穿好了，像一直在等人来接。她说她叫维多利亚。埃利奥特举起蜡烛，第一次看清了她：灰褐色的眼睛，长头发，一双很干净的手。有几个角度，她的脸几乎借来了卡琳娜的轮廓；可她左边嘴角下面没有那颗浅痣，神情也更直接。

“你受伤了吗？”他问。

“没有。我刚才开门，看见走廊里有人摔倒了。灯一灭，我就不敢出去了。”

门房说他走在前面。维多利亚看着埃利奥特，问能不能由他陪她下去。他伸出手，她就握住了。她没解释梦，也没问谁更清醒，只是把整个人的重量放进他的手心。他握得很稳。

回到大厅，十三个人已经凑不齐了。厨房帮工说，行李员去电梯井那边找备用电源，一直没回来；门房拿着蜡烛去找他，几分钟后也没了消息。有人猜他们自己出去避风了，有人说门一直是锁着的。女经理重新分了煤油灯，让每两个人互相照看。她始终没说出“谋杀”两个字，埃利奥特也没有。他只听见脚步声越来越少；那把撬棍还卡在电梯门缝里。

维多利亚坐在宴会厅门边。他给她找来一条干毯子，问她能不能自己走到亮的地方。她点头，起身的时候却抓住了他的袖子。

“你要是找到出去的门，别只告诉我方向。”

“我来带你。”

“你不认识我。”

“那也不妨碍我带你出去。”

她笑了一下。埃利奥特想起卡琳娜总会先问他看见了什么，发现自己在等维多利亚露出同样的怀疑。她没有。她只让他把毯子往她肩上提了提，好像救援真能从这么一件小事稳稳地开始。

就在这时，一只鸟撞上了楼梯间的彩窗。

玻璃没有碎，沉重的拍翅声却传遍了侧廊。女经理在几步外停住了，煤油灯往左歪了一点。她盯着那扇彩窗，喉咙像忘了怎么吸气。埃利奥特看见了。可维多利亚已经攥紧了他的手。

“别走开。”维多利亚说。

他带她退到避风的柱子后面。再回头时，女经理已经把灯扶稳，去看通往服务间的门了。她没有叫他。

＊

女经理说，服务间里可能有应急线路。埃利奥特不肯再让维多利亚一个人坐在大厅，就让她一起去。三个人穿过一段铺着红地毯的短廊。服务间有两个门，女经理先推开靠左的那扇，确认里面不是电梯井，才让他们进去。

维多利亚手里攥着1814的钥匙。她说是离开客房时顺手拿的，铜很凉，一直硌着手心。埃利奥特叫她收进口袋，免得又划伤。女经理看了那把钥匙一眼，没有说话。

屋里是一部旧电话、一排空钥匙钩、几只铁柜，没有电闸。埃利奥特正要问女经理是不是记错了线路，走廊上有人喊救命。声音很近。他出去看，门在身后合上了。

走廊里没有人。他回身推门，推不动。

“开门！”

门里传来女经理的声音：“先去看另一道门。”

“她还在里面！”

他用肩膀撞。门从里面抵住了。他撞了一次，两次，第三次，门终于开了。煤油灯倒在电话旁边，火还亮着。维多利亚躺在地上，脖子上一道勒痕，眼睛睁着。

她不像卡琳娜了。刚才借来的那点熟悉，跟着体温一起退了下去，只剩一个实实在在抓过他袖子的年轻女人。

他跪下来，知道已经晚了。她手里没有钥匙，口袋也是空的。他抬起头。女经理站在屋子另一头那扇门口，和他、和维多利亚之间，隔着一段完整的地板。

他用手背碰了碰维多利亚的额头，又后悔做了这个动作。她不是姐姐，也不是卡琳娜。她是他刚才答应要带出去的人，而他连她一个人在这屋里待了多久都说不准。他想把她抱出去，至少让大厅里的人知道这里发生了什么。烟已经把那条廊道压低了。他扶起她，她的手就软软地滑开了。他只好把毯子盖到她肩上。那是他在宴会厅里找来的毯子，还有一点暖，现在什么也帮不上了。

“我刚才听见有人喊。”他说，不知道是在跟女经理解释，还是在给自己找一个能受得住的理由，“我以为你们都在屋里。”

女经理没有回答。楼下的火已经越过了第一道门，大厅那边传来别的声音。

“你一直在她旁边。”他说。

“我跟你们一起进来的。”女经理没有否认，“楼下还有人。你现在跟我走，还是守在这儿？”

他以为自己会扑过去，或者一直问她是怎么下的手。可烟从另一侧的门缝涌进来，温度在往上升。维多利亚已经不能跟他走了，大厅里还有人在动。他捡起煤油灯，跟着女经理进了服务楼梯，关门之前，又回头看了维多利亚最后一眼。

火在下面。他们只能往上。

＊

楼梯一层比一层古怪。女经理认得地毯底下能走的窄梯，认得布草间后面藏着的小门；埃利奥特凭着在废墟里摸过的焦痕，知道哪一段平台后来塌了，哪一扇门会被烧坏的家具堵死。他们争了好几次，才发现两个人说的不是同一个时候的酒店。她走在楼还完整的那一边，他总是提前避开以后会断的那一边。

“你怎么知道这里会塌？”她问。

“因为我见过它塌了以后的样子。”

“我也见过它以前的样子。”

她说“以前”的时候，带着一种在这里住了很久的累，不像一个经理在回想工作路线。埃利奥特想起卡琳娜说过，她有时分不清自己的记忆是从那个房间来的，还是后来别人拿给她看的。他开始怀疑，女经理那张脸，从来就不是一个靠得住的答案。

到十六层的转角，墙后又响了三下。女经理没有停，伸手扶住了他左手腕那个地方。那是他在谈话室里一听见动静就会按住的地方。他甩开她。

“你从哪儿学的这么扶我？”

“你一听见声音，就先去摸那儿。”

她给得出解释，却解释不了，她为什么知道他不愿被人从背后拉住。埃利奥特没再问。楼梯尽头有一扇半开的门，门背上有一块褪色的“1814”印子，像是钥匙牌在那里挂过很久。

女经理抬手去关门。煤油灯一晃，她的袖口露出黄铜的一角。

他一把按住。

1814的钥匙掉在地毯上，短短地、实实地响了两声。

维多利亚进服务间的时候还攥着它。出来的时候，她已经死了。现在，它在这个女人身上。

他想起卡琳娜说过的那把钥匙：很多年前有人把它拿到她面前，问她为什么拿着它，她答不上来，也不知道自己到底拿没拿过。在那个“很多年前”里，一把钥匙可能只是让她背上了指控；在今晚这里，钥匙是真的跟着维多利亚的死，到了她手里。

他再去看女经理的眼睛。彩窗前喘不上气的那一下。柜台上那三下和两下。对他左手腕的熟悉。她认得这栋楼活着的样子，他认得它死了以后的样子。这几件事终于不再是互不相干的巧合了。

“从大厅开始就是你。”埃利奥特说，“不是她。”

女经理没有替他承认。她把煤油灯放在台阶上，等他自己把她看清楚。

短发和制服还在他眼前，却遮不住那双灰褐色的眼睛了。他想起又直又长的黑发，薄薄的刘海，左边嘴角下面那颗很浅的痣。卡琳娜站在他刚刚走过的那条路上，没有从别的地方忽然冒出来。

“你一直知道我在。”她说。

他看着她。“我只知道你可能在。我把另一个人当成了你。”

卡琳娜弯腰捡起钥匙，不再装经理了。远处有人喊开门，喊声很快被烟呛断。她没有让他去追，也没有把维多利亚说成一个可以收回的错。

“我看着你把她从房间里带出来。”她说，“你连问都没问，她愿不愿意从那扇门走。”

“她说需要我。”

“所以你就知道怎么帮她了。”

他想说他也帮过她：窗边的鸟，走调的琴，那道涂黑的墨。他没说出口。

＊

他们顺着服务楼梯往下走。最底下那扇防火门上，红字还是“出口”。门一推开，外面竟是屋顶。水箱立在大雨里，像整栋酒店的楼层都被折到了这一处。卡琳娜站到他旁边，把1814的钥匙塞进他手心。

“我们都已经到这儿了。别让我一个人先醒。”

“这里不一定是出口。”

“你怎么知道你拒绝了以后，我们还会在哪儿见面？”

“我不知道。”埃利奥特握紧了钥匙，“但我不能答应跟你一起死。”

她抬眼看他，等他把后半句说完。

“我不想你死。”

“你把我留在这里，就觉得我能活？”

“我不知道你会怎么活。”他的声音低下去，“我知道我想让你有机会。你可以生我的气，可以到了别的地方以后不再来找我。那都比我现在答应你去死好。”

卡琳娜伸出来的手停在半空。

“那你还是会让我去。”她说。

“我会尽我能做的留住你。可不能拿你的命当条件。”

卡琳娜走近一步，两只手臂环住了他。埃利奥特没有退。上一次在洗衣车旁边，他只来得及看着她替他按平衣领；这一次，他们终于抱住了对方，雨水从两个人的头发里流下来。他还想告诉她，他认得她，已经不需要那把钥匙了——

肋下一阵剧痛。

卡琳娜抱得很紧。他手里的钥匙掉在地上，那一声比身后的火还清楚。

“你会醒在哪儿？”他问。

“有你的地方。”她说。

他没有再问她怎么知道。他的手停在她背上，想起她在医院里一个人对着空白页的样子。火沿着楼梯往上烧，屋顶上还下着大雨。他最后看见的，不是女经理，也不是维多利亚，是卡琳娜自己的脸。

## 改动说明（不属于正文）

### 一、本章不能动的东西（已逐项守住）

- **接回第一章同一次坠落**，男主独有外层梦：朋友的车不见了、酒店绕回面前、三楼客房用椅子抵门、墙后三下 → 睡去进入内层杀人夜：一九八一年、翻页钟、圣诞舞会菜单、停电、十三人五女、女经理、柜台三下＋两下 → 1814、维多利亚（借来卡琳娜的轮廓、没有痣）→ 两人失踪、撬棍 → **鸟撞彩窗，女经理僵住，他先护维多利亚（关系错选）** → 服务间、维多利亚持钥匙 → 维多利亚中段被杀、脸恢复为她自己 → 服务楼梯“两张地图”→ 十六层、扶左腕 → 钥匙从袖口滑出 → **他自己把线索连起来，主动说“从大厅开始就是你”**（卡琳娜不公布答案，环境不替他揭晓）→ 外貌脱落 → 屋顶水箱、共同死亡邀请、他拒绝（“我不想你死”）→ 拥抱中被杀。
- **信息权限**：钥匙在梦里是她杀人后拿走的罪证；“很多年前”的钥匙只是指控，不倒推旧案。正文未出现“旧案”“杀人夜”二词。
- **识别机制**：两张地图（她认得楼活着的样子，他认得它死后的样子）＋1814钥匙转移＋关系细节（彩窗、三下两下、左腕），全部由他的判断完成。

### 二、诊断清单中的条目

- **存疑 2（服务间站位）**：按推荐改第七章、第八章不动。现在他被呼救声引出门后，门在身后合上，走廊里没有人；门里传来女经理的声音“先去看另一道门”；门从里面抵住，他撞了三次才开；女经理站在屋子另一头那扇门口。这与第八章“卡琳娜关上主门……埃利奥特撞开门时，她已经站到另一边”一致。维多利亚的伤由“脖颈处有一道伤”改为“脖子上一道勒痕”，与第八章电话线勒颈一致。
- **存疑 3（楼层方向）**：补一句“火在下面。他们只能往上。”从大厅旁服务间往上到十六层，再顺服务楼梯往下抵达屋顶（梦的空间扭曲，保留“出口”红字作为稳定锚点）。开场“跌过几层腐朽木梁，落进一间宽阔的宴会厅”改为“跌穿腐朽的楼板，落进下一层的宴会厅”，再沿楼梯一路往下到侧门。
- **存疑 7**：女经理扶的位置改为“他左手腕那个地方。那是他在谈话室里一听见动静就会按住的地方”，不再说是停电那天卡琳娜摸过的地方（第三章她碰的是他右手和桌沿）。
- **第一章接口**：原稿“第一天鸟撞谈话室玻璃时，他也是先用椅背隔开声音”所在的整段叙述者评论删去（见下条），接口问题随之消失。
- **删去的解释句**：
  - 第1315行“一个人说自己需要帮助，他便有事可做”→“把整个人的重量放进他的手心。他握得很稳。”
  - 第1333行“埃利奥特很久以后才想起……他却只惦记把另一人带离”整段删去，停在“她没有叫他。”关系错选交给读者看。
  - 第1381行“他曾把卡琳娜放进愿意被救的女人身上……”删去，换成他把线索逐条排开的短句。
  - 第1399行“这个问题无法靠一句‘我也在乎你’抹平”→他想说却没说出口的三件事。
  - 第1419–1421行进入卡琳娜内心的两句删去，只留“卡琳娜伸出来的手停在半空。”
- **时代细节**：原稿“手机没有信号”与1993年的医院现在时不符，改为“街角电话亭里的听筒没有拨号音”。

### 三、意境

本章主导意象是**钥匙**：维多利亚手心的红印、“铜很凉，一直硌着手心”、袖口露出黄铜的一角、落在地毯上“短短地、实实地响了两声”、塞进他手心、最后落地“比身后的火还清楚”。辅助意象是光：一盏一盏重新分配的煤油灯、蜡烛。

### 四、对白

本章对白多数保留。改动：

| 原句 | 现句 | 原因 |
|---|---|---|
| “如果你找到出去的门，不要只告诉我方向。” | “你要是找到出去的门，别只告诉我方向。” | 口语 |
| “开门。”（他在门外，她在门边） | “开门！”／门里：“先去看另一道门。”／“她还在里面！” | 站位改为隔着门喊话 |
| “你在她身边。” | “你一直在她旁边。” | 与新站位一致 |
| “我跟着你们进来。” | “我跟你们一起进来的。” | 口语 |
| “我看到你把她带出房间。你甚至没有问她是否愿意从那扇门走。” | “我看着你把她从房间里带出来。你连问都没问，她愿不愿意从那扇门走。” | 口语，更有力 |
| “我们既然都到了这里，别让我一个人先醒。” | “我们都已经到这儿了。别让我一个人先醒。” | 拆成两句 |
| “那你仍然会让我去。” | “那你还是会让我去。” | 口语 |
